We're pleased to announce the release of

- [seL4 17.0.0](https://docs.sel4.systems/releases/sel4/17.0.0): The seL4
  microkernel
- [Microkit 2.4.0](https://docs.sel4.systems/releases/microkit/2.4.0): The seL4
  Microkit for building static-architecture systems
- [CAmkES 3.13.1](https://docs.sel4.systems/releases/camkes/camkes-3.13.1):
  Component Architecture for microkernel-based Embedded Systems
- [capDL 0.6.1](https://docs.sel4.systems/releases/capdl/0.6.1): Tools for
  generating, parsing and loading capability distribution specifications
- [rust-sel4 6.0.0](https://github.com/seL4/rust-sel4/releases/tag/v6.0.0): Rust
  support for seL4 userspace. See the Rust section on the
  [seL4 docsite](https://docs.sel4.systems/projects/rust/) for more
  information.

This release focussed on fixing issues in unverified configurations of seL4, as
well as auditing code in verified configurations that is not covered by the
scope of seL4's formal proofs. Like previous releases, this release contains
security relevant changes and we recommend upgrading to the latest version of
seL4.

We would like to thank Anthropic for reporting a number of these issues and for
the constructive, actionable and useful way they were communicated. Overall,
this audit has strengthened the security of seL4 in all parts of the kernel that
the formal proofs do not make guarantees about.

seL4 17.0.0 and the corresponding Rust support have breaking changes and will
require updates if you are using the seL4 API directly. The CAmkES and capDL
tool releases are backwards compatible. The Microkit contains security and bug
fixes and has breaking changes.

As always, a more detailed list of the changes and user-visible impact can be
found in the [seL4 release
notes](https://docs.sel4.systems/releases/sel4/17.0.0.html) and the [seL4
docsite](https://docs.sel4.systems), together with upgrade instructions.

Enjoy!
